# Streaming target-speaker extraction benchmarks

Research snapshot: 2026-10-10. Primary-source landscape scan for muse-c; no model was installed, trained or benchmarked.

Generated from [tse_benchmarks.json](tse_benchmarks.json). Regenerate with `.venv/bin/python -m eval.tse_benchmarks > docs/research/TSE_BENCHMARKS.md`. The JSON is authoritative; the renderer works offline.

A reported best means the strongest result within the named paper/table or official track, not a certified global SOTA as of the snapshot. Custom datasets and reference baselines are explicitly labelled.
SI-SDRi, SI-SNRi, SDR, SDRi, TER and learned MOS proxies retain the authors’ labels. They are not interchangeable. Corpus, duration mode, noise, sample rate, enrollment and scoring conditions travel with each result.
Streaming status refers to the listed result. verified-subsecond means cited source timing, not independent replication. protocol-subsecond is a challenge rule, not measured total latency. causal-unverified does not prove bounded output delay.
Publication/revision year accompanies paper results. Maintainer README results use the observation year where publication year is unavailable. All quantitative claims have a source, locator and conditions in the JSON.

## Focused hunts

### Enrollment-free and short enrollment

USEF removes the speaker embedding network, not the enrollment. Mixture-derived WavLM embeddings avoid external enrollment; visual extraction replaces it with a visual cue. LExt short-cue results are offline. [usef](https://arxiv.org/html/2409.02615v3) [crowd](https://arxiv.org/html/2604.03219v1) [clear](https://github.com/modelscope/ClearerVoice-Studio/blob/main/train/target_speaker_extraction/README.md) [lext](https://arxiv.org/html/2505.05114v1)

### Matched falsification protocol

- budget: Proposed cap: thirty GPU minutes total, including warmup; stop rather than expanding training. This is an experiment budget, not a measured runtime.
- preflight: Freeze source commits, checkpoint hashes/licenses, configuration, mono sample-rate/channel contract, and exact mix/target/enrollment SHA-256 manifest. Abort scoring if no genuine target reference or held-out split. Remote resident inputs must be verified by executor; local manifest presence is not remote availability.
- baseline: Freeze current MossFormer2 separation plus ECAPA selection configuration and weights; retain raw input and oracle stream choice as diagnostic controls. Same device, precision, clips, reference crop and permitted delay for each comparison.
- identity_arm: Use unchanged separator streams. Compare ECAPA with permitted reference-feature identity scoring on short clean and contaminated utterances; reference utterance must not overlap scored mix. Report wrong-speaker intervals and abstentions; do not call whole-extractor score an isolated identity gain.
- streaming_arm: Only run a candidate after causal weights and state API exist. Feed chronological mono hops, reset between sessions, flush consistently, and perturb future samples to detect future dependence. Match delay/crop to baseline and report algorithmic delay separately from compute.
- outputs: Per-case strict JSON: manifest/checkpoint/config hashes, device, elapsed GPU time, active-target SI-SDRi on aligned shared crop, target-absent energy ratio, wrong-speaker time, p50/p95 compute, RTF and listening artifact paths. Missing references mean the associated metric is unavailable, never fabricated.
- stop_rule: Reject only this tested configuration if it leaks identity, exceeds delay/deadline, or regresses quality in the matched arm. Missing weights, unavailable phone stems, binaural mismatch or failed setup are feasibility uncertainty, not permanent method rejection.
- reproduction: Executor uses existing eval harness with frozen manifest and configuration and records exact command and environment. This proposal is not an executable adapter or a completed GPU trial.
