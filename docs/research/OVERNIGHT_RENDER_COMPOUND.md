# Compound heldout challenge bank

`eval/prep_render_compound.py` prepares an evaluation-only bank from an existing fixture index.
It does not train, download, or modify source records. Source groups are frozen by a SHA-256
key over dataset/split, speaker IDs, and source IDs; role swaps and conditions stay within that
group. The default cap is 600 cases, generated by round-robin source group selection.

## Exact invocation

Generate or reuse an existing development/heldout fixture set, then run:

```sh
.venv/bin/python -m eval.prep_render_compound \
  --source-root "$HEARING_FIXTURES_DIR" --source-set full \
  --out "$HEARING_FIXTURES_DIR/compound_heldout" --cap 600
```

For the first immediate smoke shard:

```sh
.venv/bin/python -m eval.prep_render_compound \
  --source-root "$HEARING_FIXTURES_DIR" --source-set tiny \
  --out "$HEARING_FIXTURES_DIR/compound_heldout" --cap 12
```

The output contains `index.json`, `checkpoint.json`, and one directory per case with
`mix.wav`, `target.wav`, `interferer.wav`, `noise.wav`, and `manifest.json`. Every manifest
labels the source ID/group, role swap, recipe, hard target SIR (`-10` or `-15` dB), source
split, and whether the swapped transcript was available. `mix` is the float32 sum of the three
saved stems before WAV quantisation; no clean stem is overwritten. The two recipes are:
`pause_onset` and `noise_reverb_pitch_bandlimit` (onset/pause plus deterministic pink-noise,
35-ms early-reflection reverb, +/-2 semitone role pitch shift, and 250-3600 Hz band limit).

The renderer is checkpointed after every case. To resume the same plan, use the same source
index and cap with `--resume`; a changed index or cap is rejected by the plan hash. To stop
cleanly, create the named stop file (`--stop-file /tmp/compound.stop`). `render.pid` and
`render.log` live beside the output while running; the process is CPU-only and bounded by
`--cap` (no claim is made about model metrics or rendering duration). Output is intended for
the shared ignored generated-fixtures root, not version control.

This bank is a challenge artifact only. Consumers must load each case's manifest, preserve its
`source.source_group` split, and report missing transcripts as unavailable rather than infer
them. Do not use these cases for training or tune thresholds on them. No overnight render was
run in this worker; therefore no measured latency, quality, or coverage number is reported.
